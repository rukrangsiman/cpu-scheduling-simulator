   - เปิดกล่องเลือกสีแล้วเลื่อนแถบซ้าย กล่องต้องเลื่อนตามจุดสี (AI ทดสอบด้วยการส่ง event เอง ยังไม่ได้ลองเลื่อนด้วยเมาส์จริง)
   - ค่าสรุป 4 ช่องบนมือถือ (D-037): ไอคอนอยู่เหนือชื่อ กราฟอยู่ใต้ตัวเลข ชอบไหม / ปุ่ม "Randomize Burst Time" ภาษาอังกฤษตอนนี้อยู่แถวของตัวเอง

   - ป้ายสถานะบนการ์ด CPU (D-034): ชัดพอไหม สีและขนาดพอดีไหม (ขนาดปรับที่ `.cpu-card-status` สีปรับที่ `--status-*` ใน css/style.css)

   - ชุดสีโปรเซส (D-021 / D-036) และแถวโปรเซส 2 คอลัมน์ + ปุ่มลูกศรกาง/พับ (D-018) ใช้สะดวกไหม
   - ชุดสี Cream / Ink, หัวข้อกึ่งกลาง, ความเด่นของการ์ด CPU ที่เลือก, ดวงอาทิตย์พื้นหลัง (ความจางปรับได้ที่ `--sun-opacity` ใน css/style.css)
   - popup 3 แบบ (รายละเอียด CPU / วิธีทำงาน / ตั้งค่า) ครบตามที่ต้องการหรือยัง — popup ตั้งค่าตอนนี้มีสวิตช์ Animation พื้นหลัง (D-041) + ล้างข้อมูล และไอคอนเป็นแถบเลื่อน (D-040)

## ℹ️ ข้อสังเกต (ยังไม่แก้ เพราะอยู่นอกงานนี้)
- ข้อความ `noBurstInputs` ใน `js/validation.js` ยังอ้างถึง "ปุ่มถัดไปในขั้นที่ 1" ของหน้าเดิม — ในหน้าปัจจุบันไม่มีทางเกิดข้อความนี้ (มีแถวโปรเซสอย่างน้อย 1 แถวเสมอ) ถ้าจะแก้ต้องแก้ test ที่ตรวจข้อความนี้ด้วย
- ถ้ากรอก BT ว่างบางช่อง `validation.js` จะแจ้งเฉพาะช่องว่างก่อน ช่องที่กรอกผิดรูปแบบ (เช่น `2.5`) จะแจ้งในการกด Run ครั้งถัดไป (พฤติกรรมเดิม)
- ข้อมูล CPU ใน localStorage แยกตามที่อยู่ของไฟล์ ถ้าย้ายโฟลเดอร์โปรเจกต์หรือเปิดผ่าน server CPU ที่สร้างไว้จะไม่ตามไปด้วย (ธีมและภาษาก็เป็นแบบเดียวกัน)
