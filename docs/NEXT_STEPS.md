   - ตรวจคำแปลภาษาอังกฤษใน `js/i18n.js` ว่าใช้คำตรงกับที่เรียนในวิชา
   - เสร็จเมื่อ: สมาชิกยืนยันว่าใช้ได้ หรือแจ้งจุดที่ต้องแก้
2. **กรอกข้อมูลใน README** — ชื่อวิชา, ชื่อ-รหัสนักศึกษาสมาชิก 3 คน, ชื่อ Editor
   - เสร็จเมื่อ: README หัวข้อ 5 และ 8 ไม่มี `______`
3. **ทดสอบเปิดจริง** — double-click `index.html` ใน Chrome และ Edge แล้วทำ TC-01, TC-02, TC-03, TC-V01–V08
   - ลองสลับธีมและภาษา แล้วปิด-เปิดไฟล์ใหม่ ธีมและภาษาที่เลือกต้องยังอยู่
   - กดช่องสี → "กำหนดเอง (RGB)" ต้องเปิดกล่อง RGB ของ browser ได้ (AI ทดสอบส่วนนี้ด้วยการกดจริงไม่ได้)
   - กรอก version ของ browser ใน README หัวข้อ 5 (ดูที่ `chrome://version`, `edge://version`)
   - เก็บภาพหน้าจอ (แนะนำ `docs/screenshots/`) และติ๊ก ⬜ ใน `docs/TEST_CASES.md`
   - กรอกชื่อผู้ทดสอบในตาราง README หัวข้อ 7
4. **คำนวณมือ TC-01** แล้วลงชื่อใน `docs/TEST_CASES.md` และ README หัวข้อ 6 (R1.6d — ข้อบังคับ)
5. **อ่านและอธิบายโค้ด** — Role A: `js/scheduler.js`, Role B: `js/validation.js` + `js/ui.js` + `js/theme.js` + `js/i18n.js`
   คำถามฝึก:
   - ทำไม FCFS กับ SJF ใช้ `runInOrder` ร่วมกันได้
   - ทำไม RR ต้องเช็ก `startTimes[index] === null` ก่อนบันทึก ST

   - ทำไมกดคำนวณซ้ำแล้ว BT ที่สุ่มไว้ไม่เปลี่ยน
   - ทำไม `theme.js` โหลดใน `<head>` แต่ `ui.js` โหลดท้าย `<body>`
   - ทำไมแก้จำนวนโปรเซสแล้วกดไปขั้นที่ 2–3 จากแถบด้านบนไม่ได้ (`onProcessCountInput`, `canVisitStep`)

   - ทำไมสูตร ST/CT ของ Round Robin ต่างจาก FCFS/SJF (`explainStartTime`, `explainCompletionTime`)
6. **ทบทวน `docs/AI_LOG.md`** — ใส่ชื่อในช่อง "ผู้ใช้ AI" และเปลี่ยน ⬜ เป็น ✅ พร้อมชื่อผู้ตรวจ (AI-001 ถึง AI-007)
